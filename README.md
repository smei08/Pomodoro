# Pomodoro Timer

A clean, minimal Pomodoro timer to help manage focus sessions and breaks — built with vanilla HTML, CSS, and JavaScript.

🔗 **[Live Demo → pomodorotimerv1.netlify.app](https://pomodorotimerv1.netlify.app/)**

---

## Features

- **Three Timer Modes** — Pomodoro, Short Break, and Long Break
- **Adjustable Durations** — increment or decrement each timer length to suit your workflow
- **Start / Reset Controls** — full control over each session
- **Deployed on Netlify** — accessible from any browser, no install needed

---

## Tech Stack

| Technology | Purpose |
|---|---|
| HTML | Structure |
| CSS | Styling and layout |
| JavaScript | Timer logic and interactivity |
| Netlify | Deployment and hosting |

---

## Getting Started

No build step needed — just open the file directly.

```bash
# Clone the repo
git clone https://github.com/smei08/Pomodoro.git
cd Pomodoro

# Open in browser
open index.html
```

Or use a local dev server like [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in VS Code.
